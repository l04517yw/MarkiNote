## 🌟 What is MarkiNote?

MarkiNote is a handy little tool that helps you manage and preview Markdown documents! Imagine you have tons of notes, documents, and tutorials—all written in Markdown—but scattered across various folders... Feels messy, right? (>_<)

**Don’t worry—MarkiNote has got your back!** ヾ(≧▽≦*)o

It can:
- 📁 Neatly organize all your Markdown files
- 👀 Let you preview rendered Markdown in real time
- ✨ Support advanced features like math formulas, code highlighting, Mermaid diagrams, and more!
- 💾 Make managing and viewing all your notes easy and convenient

## 🚀 Step 1: Launch the App

### It’s super simple!

**Step 1: Open your terminal/command line**

Don’t be scared—it’s really easy! (｡♥‿♥｡)

## 📤 Step 2: Upload Your First File

Now let’s upload some files! (ﾉ◕ヮ◕)ﾉ*:･ﾟ✧

### Uploading a Single File

1. Click the **"📁 Upload"** button in the left sidebar  
2. In the pop-up dialog, choose **"Upload File"**  
3. Select a `.md`, `.markdown`, or `.txt` file  
4. Click OK—your file is now uploaded!

### Uploading an Entire Folder

Got lots of files? You can upload a whole folder at once! (๑•̀ㅂ•́)و✧

1. Click the **"📁 Upload"** button  
2. Choose **"Upload Folder"**  
3. Select your folder  
4. All files will be uploaded while preserving their original directory structure!

### Creating a New Folder

Want to organize your files? Creating folders is super easy! (´｡• ᵕ •｡`) ♡

1. Click the **"📂"** icon (New Folder button) on the left  
2. Enter a folder name  
3. Click "Create"  
4. Done! ✨

---

## 👀 Step 3: Preview and Edit

### Previewing Documents

Previewing documents couldn’t be simpler! (≧▽≦)

1. Find the file you want to preview in the left file list  
2. Click the filename  
3. The rendered Markdown content will appear on the right!

**Super smooth, super fast!** ⚡️

### Viewing Source Code

Want to peek at the raw Markdown code?

1. After previewing a document, click the **"</> View Source"** button in the top-right corner  
2. A window will pop up showing the original code  
3. You can even click "Copy" to copy it instantly!

### 🔢 Math Formula Support

MarkiNote supports LaTeX math formulas—super powerful! (ง •̀_•́)ง

**Inline formulas** (inside sentences):
```markdown
This is an inline formula: $E = mc^2$
```
Result: This is an inline formula: $E = mc^2$

**Block formulas** (centered on their own line):
```markdown
$$
\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}
$$
```
Result:
$$
\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}
$$

## 📁 File Management Tips

### Right-Click Menu

Right-click any file or folder to open a handy context menu! (｡･ω･｡)ﾉ♡

- **Preview**: Quickly preview the file  
- **Move to...**: Move the file to another folder  
- **Delete**: Delete the file or folder (use with care!)

### Moving Files

Organizing files is super convenient! (≧∇≦)ﾉ

1. Right-click the file you want to move  
2. Choose "Move to..."  
3. In the pop-up window, select the destination folder  
4. Click the folder name to confirm

### Breadcrumb Navigation

The breadcrumb navigation at the top-left helps you jump quickly to any folder level!

Example: `Root > Study Notes > Python > Basics Tutorial`

## ❓ Frequently Asked Questions

### Q1: I get “Unsupported file format” when uploading—what should I do?

**A:** MarkiNote only supports these formats:

- `.md` (Markdown)  
- `.markdown` (Markdown)  
- `.txt` (Plain text)

Please make sure your file is one of these! (｡･ω･｡)

### Q2: My math formulas aren’t showing up?

**A:** Please check the following:

1. Is your formula syntax correct?  
2. Inline formulas must be wrapped in single dollar signs, like: `$E=mc^2$`  
3. Block formulas need double dollar signs or bracket notation  
4. Try refreshing the page

### Q3: How do I delete a file?

**A:** Here’s how:

1. Right-click the file  
2. Select "Delete"  
3. Confirm deletion

⚠️ **Note**: Deleted files cannot be recovered—please be careful!

### Q4: Can I open multiple files at once?

**A:** Currently, you can only preview one file at a time! To switch, just click another filename in the left file list. (●´ω｀●)

### Q5: I have so many files—how can I find what I need quickly?

**A:** For now, try these tips:

- Organize with folders  
- Name files by date or topic  
- A search feature is coming in future versions—stay tuned! ✧*｡٩(ˊᗜˋ*)و✧*｡

## 🎯 Tips & Best Practices

### 📝 File Naming Tips

Good filenames save you time! (๑•̀ㅂ•́)و✧

**Recommended naming styles:**
- `2024-01-15-PythonBasics.md` (with date)  
- `DataStructures-LinkedListNotes.md` (category + topic)  
- `Project-MarkiNoteDevLog.md` (project + description)

**Not recommended:**
- `Untitled.md` ❌  
- `New Text Document.md` ❌  
- `asdfgh.md` ❌

### 📂 Folder Structure Suggestions

A thoughtful folder structure makes everything easier to find! (★ ω ★)

**Example structure:**
```
lib/
├── Study Notes/
│   ├── Python/
│   ├── JavaScript/
│   └── Data Structures/
├── Project Docs/
│   ├── MarkiNote/
│   └── Other Projects/
├── Book Notes/
└── Daily Journal/
```

### ⚡ Performance Optimization Tips

1. **Avoid huge files**: Keep individual Markdown files under 5MB  
2. **Use image links**: For many images, use external hosting instead of local paths  
3. **Clean regularly**: Delete unused files to keep your Library tidy

### 🎨 Markdown Writing Tips

1. **Use heading hierarchy**: Structure your docs with `#`, `##`, `###`  
2. **Leverage lists**: Lists make content clearer  
3. **Specify language in code blocks**: Better highlighting!  
4. **Use tables wisely**: Great for complex data  
5. **Add emojis**: Makes your docs lively and fun! ヾ(≧▽≦*)o
